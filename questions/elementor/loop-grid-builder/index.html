What Is the Elementor Loop Grid and When Would I Use It?

SHORT ANSWER

The Loop Grid widget (an Elementor Pro feature) displays a repeating grid of items — blog posts, WooCommerce products, or any custom post type — where each item's layout is designed once as a Loop Item template, then applied to every matching item automatically, with query controls for filtering, sorting, and pagination, similar in purpose to a custom archive page but usable anywhere, including within a regular page.

ON THIS PAGE

  1. How the Loop Grid Works
  2. Common Use Cases
  3. Setting One Up

How the Loop Grid Works

Setting up a Loop Grid starts with creating a Loop Item template, designed visually with Dynamic Tags representing whatever will vary per item (title, image, price, excerpt). The Loop Grid widget then queries a chosen post type according to configured filters (category, tag, custom taxonomy, order), and renders the Loop Item template once for each matching result, arranged in a responsive grid.

Common Use Cases

  • A custom-designed blog listing embedded within a regular page, rather than relying on a full Theme Builder archive template.
  • A related-products or featured-products grid on a WooCommerce page, filtered by category or a specific product query.
  • A team members or portfolio grid built from a custom post type, each item using a consistently designed card template.
  • A filterable content section where visitors can narrow results by category or taxonomy directly on the page, using Loop Grid's built-in filter widget pairing.

Setting One Up

  1. Create a Loop Item template and design it with Dynamic Tags for the fields that should vary per item.
  2. Add the Loop Grid widget to a page and select the Loop Item template to use.
  3. Configure the query — post type, filters, sorting, and how many items to show per page.
