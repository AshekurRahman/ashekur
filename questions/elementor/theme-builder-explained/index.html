What Is Elementor's Theme Builder and What Does It Control?

SHORT ANSWER

Elementor's Theme Builder (an Elementor Pro feature) lets you visually design the structural parts of a site that normally live in theme template files — the header, footer, single post or product template, archive/category pages, and search results — then apply each design site-wide, or to a specific subset of content, through its own set of display conditions rather than editing individual pages one at a time.

How It Actually Works

Rather than editing a specific page, each Theme Builder template is designed once and then assigned display conditions — "Entire Site," a specific post type, a category, or an individual page — determining where that template actually renders. Because it overrides the theme's own template files for the conditions it matches, a Theme Builder header replaces the active theme's header everywhere those conditions apply, without needing to touch the theme's code directly.

What You Can Build With It

  • Header and footer templates, the most common use, replacing the theme's default header/footer across the whole site or specific sections.
  • Single post/product templates, controlling the layout for individual blog posts or WooCommerce product pages, including dynamic content pulled from that specific post or product.
  • Archive templates, controlling how category, tag, or shop listing pages display, including the loop layout for each item.
  • Search results and 404 pages, giving a fully custom design to pages that would otherwise use the theme's often-plain default.
  • Multiple templates with different display conditions can coexist — a different header for a landing page section versus the rest of the site, for instance, with priority settings resolving any overlap.

Getting Started With It

  1. Go to Templates → Theme Builder in the WordPress admin to create a new template of the desired type.
  2. Design the template visually using the same Elementor editor used for regular pages, including dynamic tags where relevant.
  3. Set display conditions to control exactly where the template applies, checking priority if conditions overlap.

RELATED ELEMENTOR QUESTIONS

What's the Point of Elementor's Global Colors and Fonts? Defining a color or font once as global and reusing it everywhere means a single future update changes it site-wide, instead of hunting element by element.
Can I Show or Hide an Element Based on a Condition? Elementor Pro's Display Conditions widget setting hides/shows elements per user role, device, date, or a custom rule without duplicating pages.
Elementor Container vs. Section: What's the Difference? Container is the newer, single flexbox-based layout element replacing the older Section/Column/Inner Section structure with more flexible nesting.
Can I Copy Just the Styling From One Element to Another? Yes — right-click an element and use Copy Style, then Paste Style on the target, applying its design settings without touching its content.
