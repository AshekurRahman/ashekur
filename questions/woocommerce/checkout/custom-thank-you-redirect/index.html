Can I Redirect Customers to a Custom Page After Checkout?

SHORT ANSWER

Yes, WooCommerce's woocommerce_thankyou hook fires after an order is successfully placed and can be used to redirect to a custom page instead of showing the default order-received template — commonly used for a custom post-purchase upsell offer, a customer survey, or a thank-you page with specific tracking/conversion pixels the default template doesn't accommodate as cleanly.

ON THIS PAGE

  1. How to Implement This
  2. Things Worth Getting Right
  3. Implementing It Properly

How to Implement This

The woocommerce_thankyou action passes the order ID, giving access to full order details before deciding where to redirect — this makes it possible to build conditional logic (redirect only for a specific product, or only for first-time customers, for instance) rather than a single, blanket redirect for every order.

add_action( 'woocommerce_thankyou', function( $order_id ) {
    if ( ! $order_id ) {
        return;
    }
    wp_safe_redirect( home_url( '/thank-you-custom/?order=' . $order_id ) );
    exit;
} );

Things Worth Getting Right

  • Passing the order ID through to the custom page if it needs to display order-specific content, since the redirect can include it as a query parameter for the destination page to read.
  • Conditional redirects based on product, order total, or customer type need the logic built into the same hook, checking order details before deciding whether (and where) to redirect.
  • Analytics and conversion tracking scripts that expect to fire on the default order-received page need to be moved to the new custom page instead, or duplicated there, to avoid losing tracking data after this change.
  • Testing with a real completed order (not just a page preview) is essential, since this hook only fires in the actual post-checkout flow.

Implementing It Properly

  1. Use the woocommerce_thankyou hook with a safe redirect, including the order ID if the destination page needs it.
  2. Move any conversion tracking scripts from the default template to the new custom destination.
  3. Test with real completed orders across different scenarios if the redirect is conditional.
