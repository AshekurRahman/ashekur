What this tool checks

Paste in a URL and this tool fetches the site's public homepage — the same page a browser or search engine already loads — and looks for three independent signals. First, module types that only exist in Divi 5 (Timeline, Breadcrumbs, SVG, Table of Contents, Instagram Feed, Tooltip, Post Filter, Charts, Gravity Forms, Imagely Gallery, Payment Button) and never existed in Divi 4 — finding one is unambiguous proof of Divi 5. Second, the theme or plugin's own version number, read from the ?ver= query string WordPress adds to its own assets by default. Third, a rough count of et_pb_module wrapper elements on the page, as a lower-bound proxy for how much is actually built there.

Why it sometimes can't tell

Neither of the two version signals survives everywhere. A caching or optimization plugin commonly strips ?ver= query strings from asset URLs before they reach the browser, and a homepage doesn't always happen to include a Divi-5-only module — those are more common on inner pages built with specific modules. When neither signal is present, this tool reports the version as unknown rather than guessing which one it is. There's also no way to detect Divi 5's backward-compatibility mode from the outside — the badge for that only shows inside the logged-in WordPress admin bar — so this tool never claims to see it.

Why this matters if it's your own site

Divi 5 rewrote the Visual Builder in React specifically to fix the editor-speed complaints that dogged Divi 4, and paired it with a Design System — Elegant Themes' answer to Elementor's Global Kit. A site still running old Divi 4 layouts needs a deliberate move into Divi 5's builder and Design System to actually get that benefit, and the pattern seen most often on real Divi sites is a half-migrated state: some templates rebuilt in Divi 5, others still on Divi 4 shortcodes. See Divi 4 vs Divi 5: what actually changes for a fuller breakdown of what changed and whether migrating now is worth it, or Elementor vs Divi if the platform choice itself is still open.

What to do with the result

Confirmed on Divi 4? A planned migration into Divi 5 is worth doing properly — that's exactly what Divi 5 Migration covers. Confirmed on Divi 5 already? It's still worth checking that the migration itself finished cleanly — presets carried over, nothing left half-rebuilt — the same page covers that too. Anything else that needs to change on the site, that's Divi Customization.

FAQ

Questions about this checker

Is this Divi 5 checker actually free?

Yes. There's no signup, no email gate and no limit on how many sites you can check. Paste a URL and get a result in a few seconds.

How does it tell Divi 4 and Divi 5 apart?

It checks for module types that only exist in Divi 5 (Timeline, Charts, Table of Contents and others that never existed in Divi 4), and it reads the theme or plugin's own version number from the ?ver= query string WordPress adds to its assets by default. Either signal alone is enough to confirm a version.

Why does it sometimes say the version is unknown?

A caching or optimization plugin commonly strips ?ver= query strings from asset URLs, and a homepage doesn't always happen to use a Divi-5-only module. When neither signal survives, this tool says so honestly instead of guessing either way.

Can it tell if a Divi 5 site is only half-migrated?

Not from the outside. Divi 5's backward-compatibility mode — where older content still runs on Divi 4's rendering engine inside a Divi 5 install — is only visible from the WordPress admin bar, which a logged-out check can never see. This tool reports what's confirmed, and doesn't claim that distinction.

What does the module count actually measure?

It's a lower-bound count of et_pb_module wrapper elements found on the homepage — Divi's own generic per-module class. It's a rough proxy for how much is built on that one page, not a full site audit.

It says I should upgrade — what should I do with that?

The result links straight to Divi customization, where a Divi 4 to Divi 5 migration is planned properly rather than left half-done.
