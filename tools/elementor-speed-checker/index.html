Results

What this tool checks

Enter a URL and this tool fetches the site's public homepage — the same page a browser or search engine already loads — and first confirms Elementor is actually in use. Once that's confirmed, it looks for the publicly visible causes of a slow Elementor page: known add-on library suites (Essential Addons, Crocoblock, PowerPack, ElementsKit and others) that load their own CSS and JS on every page whether or not that page uses their widgets, a high count of separate Elementor-generated stylesheets, and server response time — a hosting issue, not an Elementor one.

How to read the result

The verdict names a likely cause instead of handing you a raw score: bloated means a specific, fixable cause was found, usually add-on libraries or uncombined CSS. Slow hosting means Elementor itself looks fine but the server took too long to respond. Watch means nothing major, but a couple of things are worth keeping an eye on. Clean means no obvious Elementor-specific bloat was found on this page.

What this can't do

It deliberately doesn't try to measure your full page weight — every image, script and font byte — because fetching every linked asset from a third-party origin would multiply outbound requests per scan. Instead it reports the homepage document's own size and how many separate stylesheets and scripts it links to: an honest, verifiable proxy for request-count bloat, not a claim of exact page weight. For the full picture, a real browser-based audit alongside a look at what's actually installed catches what a public homepage fetch structurally can't.

If it comes back bloated

Add-on libraries are the single most common cause of a slow Elementor site, and it's rarely obvious from the dashboard which one is doing it — see how to improve WordPress website speed for the full pattern, or Elementor Bug Fix if you'd rather have it diagnosed and fixed directly. If the report instead points at server response time, that's a hosting problem, covered by WordPress Speed Optimization.

FAQ

Questions about this checker

Is this Elementor speed checker actually free?

Yes. No signup, no email gate, and no limit on how many times you use it. Paste a URL and get a result in a few seconds.

How is this different from a PageSpeed or Lighthouse score?

A speed score tells you the page is slow. This tool tries to tell you why, specifically for Elementor sites — add-on library bloat, uncombined CSS, or a slow server response — rather than a single number with no explanation.

What if it says my site doesn't use Elementor?

It only runs the Elementor-specific checks when it actually finds Elementor on the homepage. If your site uses a different builder or a custom theme, it says so instead of forcing an Elementor-shaped answer onto it.

Does it measure my full page weight, like images and fonts?

No, deliberately. Fetching every image, script and font from a third-party site to weigh them would multiply outbound requests per scan. Instead it reports the homepage document's own size and the number of separate CSS/JS files it links to — an honest, verifiable proxy for request-count bloat.

It found add-on bloat — what should I do with that?

See Elementor Bug Fix for the fix — trimming or reconfiguring add-on plugins so they stop loading assets on pages that don't use them. If the report instead points to server response time, that's a hosting issue, covered by WordPress Speed Optimization.
